# ₿ Bitcoin Tracker

An automated Bitcoin price tracking and analysis application built with Python. The project collects cryptocurrency market data, processes and stores it, and presents insights through an interactive Streamlit dashboard.

## 📌 Overview

Bitcoin markets operate continuously, and price data changes rapidly. This project automates the process of collecting Bitcoin market data and makes the resulting historical data available for analysis and visualization.

The project uses an automated workflow to regularly update the dataset, reducing the need for manual data collection. The processed data is then displayed through an interactive Streamlit application.

This project demonstrates a complete data workflow:

```text
Data Collection
       ↓
Data Processing
       ↓
Data Storage
       ↓
Automated Updates
       ↓
Data Analysis & Visualization
       ↓
Interactive Dashboard
